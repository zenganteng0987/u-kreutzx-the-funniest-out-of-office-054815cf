# u-kreutzx-the-funniest-out-of-office-054815cf

The Funniest Out-of-Office — a make.fun bounty entry.

`main.ts` writes one line — the funniest out-of-office auto-reply I could
write in 140 characters or fewer — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Set `OUTPUT_PATH` to write somewhere else (handy for local testing):

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
```

## The entry

> I'm out of the office. Your email will be answered in the order received, which is to say: never, and alphabetically.
